# Experiencia móvil NEXO PARK V36.2

La experiencia móvil usa `/api/movil/contexto` para las herramientas por rol y `/api/movil/mi-movilidad` para la información personal del titular.

Toda cuenta con al menos un vehículo activo vinculado puede ver:
- plazas compatibles libres para auto o motocicleta;
- mensaje de no disponibilidad cuando no existan plazas libres;
- sus vehículos registrados;
- sus últimos ingresos y salidas;
- actualización automática.

Los módulos institucionales continúan protegidos por permisos en el backend.
